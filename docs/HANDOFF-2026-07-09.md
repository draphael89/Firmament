## 1. The product in one breath

**Firmament is the vault. Glia is the guardian inside it.** A Mac-first
personal memory vault capturing three facets of one mind — **Self** (voice and
text notes), **Others** (Granola meeting transcripts), **Agents** (Claude Code
and codex session transcripts) — every entry processed by GPT-5.6 through
`codex app-server` under David's ChatGPT subscription into a title, a summary,
entities, and **at most one deepening question (abstention is first-class)**.
The differentiator, and the reason everything else exists, is the **Agent
Bridge**: when David starts consequential work in Claude Code or codex, the
agent calls `prepare_session` and receives an evidence-backed, trust-labeled,
injection-hardened packet describing who it is working for — "going from
commanding a servant to gaining the favor of a god." Capture and browsing are
substrate; steering agents is the payoff. The plan of record is
**`docs/plans/2026-07-09-firmament-plan.md`** — it was forge-hardened
(GPT-5.6 Sol spec critique, dispositions recorded in its §12) and is the
constitution of this build. When in doubt, the plan wins; when the plan is
silent, its payoff hierarchy (§3) is the tiebreaker: bridge > deepening
questions > beautiful browsing.

## 4. What exists, subsystem by subsystem (15 commits, ~6.3k lines, 51 tests green)

### Storage (`app/Sources/FirmamentCore/{Records,Migrations,VaultStore,ContentStore,VaultBrowse}.swift`)
GRDB 7 / SQLite WAL. Records: `source, entry, entryRevision (immutable, explicit
ancestry), transcriptSegment, analysisRun, entryProjection, profileAssertion,
assertionEvidence, question, job, agentSession`. Raw bytes are content-addressed
(SHA-256, atomic temp+rename, global dedup at import). Invariants **enforced and
tested** — protect these with your life:
- **Delete Now** (`purgeEntry`): one transaction removes rows + ALL jobs for the
  entry (any status — payloads can carry content) + reconciles assertions
  stance-aware (`supports+contradicts→conflicted`, supports-only→`tentative`
  even from `verified`, none→`retracted`); FTS rows fall to an `AFTER DELETE`
  trigger (provable on every path); CAS objects unlink post-commit iff the
  transaction proved them unreferenced; an open-time orphan sweep reclaims
  crash leaks; imports self-heal bytes unlinked by a racing purge (the object
  is re-put post-commit).
- **`local_only` is structural**: `pool`/`contentStore` are *internal* — the
  module API is the only write path. `entriesEligibleForEgress`, `search()`
  (default `includeLocalOnly:false`), the extraction pipeline, and the bridge
  all exclude local-only/trashed. The Mac app's browse deliberately sees
  local-only rows (operator's own UI ≠ egress).
- Duplicate import with `localOnly:true` escalates the existing entry one-way.
- `externalID` (unique per source, partial index) is connector identity —
  Granola edits become new revisions via content-hash change detection.
- Read path for clients: `VaultStore(directoryURL:readOnly:true)` +
  `browse/openQuestions/entryDetail` DTOs — GRDB never leaks across the module
  boundary. `dataVersion()` (PRAGMA data_version) lets pollers skip idle work.

### Jobs (`Jobs/JobRunner.swift`)
At-least-once, idempotency key = `revisionID:stage:promptVersion`, enqueue via
`INSERT ... ON CONFLICT IGNORE`. Failure taxonomy matters:
`usageLimitExceeded/providerUnavailable/authExpired` **park without burning
attempts** (usage-limit honors retryAfter, default +30min);
`invalidOutput/turnFailed` burn attempts with exponential backoff into a
*visible* `failedTerminal`. Stuck `running` jobs reset to pending at service
start. One runner per vault, strictly serial — the provider's handshake guard
assumes this stays true or gets revisited.

### Reasoning (`Reasoning/{ReasoningProvider,JSONRPCConnection,CodexAppServerProvider}.swift`)
`ReasoningProvider` is the seam (a local model slots in later). The codex
provider speaks line-delimited JSON-RPC on `codex app-server` stdio: initialize
→ ephemeral read-only thread per request → `turn/start` with native
`outputSchema` → async `turn/completed|failed` notifications. Hardening already
in place (hard-won, keep it): early-outcome map for the waiter/notification
race; timeout resumes the waiter (no task-group deadlock); stderr drained
(pipe-buffer deadlock); `"error": null` normalized (JSONValue.null ≠ absent!);
connection published only post-handshake; wire shapes hedged both ways
(`threadId` vs `thread.id` — **the real server sends the nested form**;
`turn.id` vs `turnId`; `agentMessage` vs `agent_message`); `connectionClosed`
and `timeout` map to `providerUnavailable` so transport trouble parks jobs.

### Pipeline (`Pipeline/ExtractionPipeline.swift`)
`extract-v1` prompt + strict JSON schema (title, summary, people/projects/
topics, decisions, open_loops, question{abstain,text,rationale,evidence}).
Model `gpt-5.6-terra` @ high (static consts; escalate to sol only if question
quality flags at Gate 3). Writes analysisRun + projection + FTS in one txn;
re-checks the revision still exists (Delete Now mid-flight wins silently);
replaces the open question on reprocess; **abstention honored** (no forced
questions — trust erosion is the product's biggest risk); local-only entries
return without ever touching the provider (tested); audio returns cleanly
awaiting the future transcription stage; decode is lenient on list fields.

### Ingestion (`Ingest/{InboxImporter,AgentSessionImporter,Granola}.swift`)
Inbox: skips dotfiles/`*.partial`, quiescence window (iCloud syncs aren't
atomic), dedup by content hash, quarantine with visible `.reason` files,
consumed files removed. Agent sessions: JSONL parsed with user turns rendered
first at highest trust, assistant output retained raw but labeled untrusted,
`isMeta`/tool-result payloads skipped. Granola: documented API
(`public-api.granola.ai/v1`, Bearer `grn_`, cursor pagination tolerant of
camel/snake keys, `include=transcript`, 404 = still-processing → skip and
retry), speaker turns → transcriptSegments (`me`/`them`/diarization label),
cursor persisted on the source row.

### Bridge (`Bridge/{BridgeService,BridgeRPCHandler,SocketServer,ServiceSocketClient,ServicePaths}.swift`)
Five agent ops (`prepare_session, ask_glia, explain_session, record_outcome,
health`) + six app ops (`capture_note, answer_question, dismiss_question,
trash_entry, untrash_entry, purge_entry`) over line-delimited JSON-RPC on a
Unix socket (`firmament/1`; path falls back deterministically to
`/tmp/firmament-<hash12>.sock` when home exceeds AF_UNIX's ~104 bytes —
both sides compute it via `ServicePaths`). Packet semantics (v0-honest per
plan §5): curated identity (`identity.md` beside the vault) + excerpt-cited
retrieval under the 40/60 budget with per-excerpt cap, dropped-candidates
manifest, honest unknowns, closing motivation frame ("The bar"). **Evidence
fences are nonce-tagged** — `<<<evidence#<nonce> ...` / `#<nonce>>>>` with the
nonce generated at render time, so imported text can neither close a fence nor
forge a `curated` block; the banner tells the agent to distrust untagged
markers; a forgery test pins this. `ask_glia` returns cited evidence or an
explicit "unknown — do not guess." `record_outcome` files searchable
Agents-facet precedent. Wire errors carry distinct JSON-RPC codes.

## 5. Operational traps already sprung — learn from our bruises

1. **The codex quota is ONE account-wide window.** A sol-xhigh review burned
   it and blocked terra extractions for hours ("try again at 2:17 AM").
   Sequence heavy codex work; never run the cross-vendor review concurrently
   with extraction verification. When exhausted, `codex exec` fails fast with
   a structured `usageLimitExceeded` — and the job queue parks correctly
   (proven live).
2. **`swift test` must run from `app/`** — the harness resets the shell cwd
   between commands, and a `cd X && swift test` chained after `git -C` will
   silently run from the repo root and fail with "Could not find Package.swift"
   while the rest of the chain succeeds. Never commit on a chained test you
   didn't see pass.
3. **SourceKit diagnostics lie** in this package ("No such module 'GRDB'",
   phantom scope errors). Trust only `swift build` / `swift test` output.
4. **`codex exec` in background needs `</dev/null`** or it blocks on
   "Reading additional input from stdin...".
5. **JSONValue `.null` is non-nil.** `"error": null` from the wire decodes to
   `.object[...]["error"] == .some(.null)`. Normalize before truthiness.
6. **GRDB async overloads**: inside async contexts `pool.read/write` require
   `try await`; in sync contexts they don't. Mixed test files bite.
7. **Swift 6 strict concurrency**: top-level `let` in main.swift is
   MainActor-isolated (annotate helpers `@MainActor`); `[String: Any]` can't
   cross actor boundaries (use `[String: any Sendable]` and upcast); labeled
   tuples don't pattern-match in `switch` optionals.
8. Unix socket paths cap ~104 bytes (hence the `/tmp` fallback); `accept(2)`
   runs on a dedicated thread; partial `write(2)`/EINTR are handled on both
   sides — keep that symmetry.
9. Screenshot verification trick for the app: launch with `FIRMAMENT_HOME`,
   find the window via CGWindowList in a `swift -e` one-liner, `screencapture
   -l <id>`, then Read the PNG.

## 9. Danger zones — things that look refactorable but aren't

- `pool`/`contentStore` internal visibility IS the egress boundary. Making
  them public "for convenience" reopens a fixed P0 class.
- The fence nonce must be generated AFTER all quoted content exists. Don't
  cache or reuse it.
- Purge's job deletion covers ALL statuses deliberately (done/terminal
  payloads carry content). Don't "optimize" to pending-only — that was bug #1.
- The single-writer assumption (one service process per vault) underpins the
  in-transaction CAS reference check, the orphan sweep at open, and the
  provider handshake guard. Multi-instance support is a real design change,
  not a config flag.
- `search()`'s `includeLocalOnly` default false is load-bearing for every
  bridge path. The app opts in explicitly; nothing else may.
- JobRunner's serial execution is assumed by `ensureStarted`'s fast path.
  Parallelize jobs only with a proper connection-handshake state machine.
