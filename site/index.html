Not an app. A substrate.

You speak one raw thought. Overnight it becomes structured knowledge — read by two clients, you and your agents, as equals.

A human edit and an agent write are the same primitive: an event appended to the Ledger. Everything visible — the graph, the search, the constitution, the sky — is a disposable Lens folded back from that one immutable truth.

The bet: as models grow more capable, the scarce input becomes personal context — values, taste, decision heuristics, the compressed prior of a specific mind. Firmament holds that prior in a portable, injectable, governed form, and the machine never holds the pen on it. It drafts, cites, and proposes; you ratify.

The audit log cannot drift from reality, because it is reality.

The ten tenets

The laws of the build. Law should read like law.

  1. I

    Append, never mutate

    The Ledger is immutable. Corrections are new events; deletion is a tombstone.

  2. II

    Every Lens is disposable

    Any view must rebuild byte-for-byte from truth, or it is contraband.

  3. III

    Egress is a ceremony

    The hot path never leaves the machine unwitnessed. Departure is explicit, logged.

  4. IV

    Voice is the front door

    Capture must survive a walk with a dog and no signal.

  5. V

    The human ratifies identity

    Constitution-core changes need an explicit human verdict. No exceptions.

  6. VI

    Agents see projections

    Every grant materializes its own world. There is no raw mode.

  7. VII

    Audit in-band

    Every access is an event in the same Ledger it describes.

  8. VIII

    Deterministic before intelligent

    Rules do what rules can, at zero token cost. Models are reserved for judgment.

  9. IX

    Delete-first

    No abstraction for a second user who will never exist.

  10. X

    Immaculate or nothing

    120 frames a second, or it does not ship.
